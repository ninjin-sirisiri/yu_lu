# Daily Chat

A smartphone app that creates occasions to talk with friends and helps people feel acknowledged.

## Terms

**Friend**:
A person with whom the user has a mutually approved friendship in the app. Friends are the candidates for random daily chat assignments.

_Avoid_: phone-book contact, external social-network connection

**Chat**:
An asynchronous conversation between friends using text and images; the participants do not need to be present at the same time.

_Avoid_: live chat, voice call, video call

**Chat Growth**:
The cumulative number of days on which both participants in a Chat send messages. It is shared by the two participants, is independent of Streak, and is retained through gaps in conversation and the ending or re-establishment of their friendship.

_Avoid_: chat streak, message count

**Streak**:
A user's consecutive days of fulfilling the daily messaging requirement. Continuation requires sending messages both to the user's Send Target and to all Reply Targets; receiving a message alone does not fulfill the requirement.

**Streak Appearance**:
The app-wide appearance earned through a user's Streak, based on the greatest day count earned for that appearance. It retains progress between milestones even when the current Streak resets.

**Send Target**:
The single friend assigned to the user for the day. The user must send a message to this friend for Streak continuation.

_Avoid_: reply target

**Reply Target**:
A friend to whom the user is assigned for the day. The user must reply after receiving that friend's message for Streak continuation.

_Avoid_: send target

**User ID**:
An identifier chosen by a user so another person can find and confirm them before sending a Friend Request.

_Avoid_: display name, internal identifier, friend code

**Friend Request**:
A request from one user to another to become Friends. It establishes a friendship only when the recipient approves it.

_Avoid_: invitation

**Invitation**:
A link or QR code shared by a user that lets another person find them and start a Friend Request.

_Avoid_: friend request, invite code
